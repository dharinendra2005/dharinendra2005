                                                      
  # n8n workflow

- Create New Workflow

- Add a Trigger Node (Manual, Webhook, Cron, etc.)

- Add an Action Node (HTTP Request, Email, Slack, Google Sheets, etc.)

- Connect the nodes by dragging arrows

- Configure each node (URL, fields, authentication, etc.)

- Test each node using “Execute Node”

- Use expressions to pass data between nodes

- Save & Activate the workflow
